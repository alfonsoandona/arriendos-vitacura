# Tablero de arriendos

_Todavía sin corridas._

Este archivo lo reescribe el radar en cada corrida con todo lo vigente,
ordenado por puntaje: dirección, comuna, **costo mensual real** (canon +
gastos comunes), metros, dormitorios/baños, antigüedad y puntaje.

Las fichas de cada departamento van en [`casos/`](casos/).

Para llenarlo: **Actions → Radar de Arriendos → Run workflow**.
